# NOLI — PROJECT.md

Стек: Next.js 14 (App Router), React 18, Prisma 5.22, Postgres (Neon) на Vercel. Адмінка за паролем (`lib/auth.js`).
Env: DATABASE_URL, ADMIN_PASSWORD, AUTH_SECRET (у Vercel і локально в .env).

## Структура головної (app/page.js)
Hero → Про мене (Audience, вкладки підприємець/роботодавець) → Як працюємо → Вибрані напрямки (4 з каталогу) → Стек (клавіатура, components/Stack.js) → FAQ → Запис (Contact, зберігає Lead).

## Рішення (скандал, швидкий режим)
- Прибрати плаваючі картки з hero (перекривали вкладки) і текст «Я Назар… із Рожища»: прийнято.
- Блок «Що роблю» прибрано, бо дублює каталог: компроміс.
- Стек: тільки те, що реально в проєкті; список у components/Stack.js, власник редагує сам.
- Ціни й терміни в FAQ без цифр, «після розмови»: прийнято.
- Нотатка «частина прикладів — навчальні/демо» лишається під міні-каталогом: прийнято.
